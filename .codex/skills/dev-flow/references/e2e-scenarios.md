# E2E シナリオ一覧

画面から確かめる主要な操作の一覧。計画役が、今回の変更経路を実際に通る行だけを、理由を添えて計画で選ぶ。実装役は選ばれた行を確認一覧（`source: "e2e"`）に入れ、確認役が実操作する。変更と関係を説明できない行は選ばない（Task 2107 では、リンク履歴の表示の変更に、通信断中のコメント編集など7行が入った）。

- 行は消さない。仕様が変わった行は、合格条件を更新し、変更した Task を添える。
- ユーザーのご指摘で見つかった、画面から確かめられる不具合は、Task が終わる時点で行を追加する。
- 初期の行は Task 2109（オフライン判定とオフライン書き込み）の確認一覧から作った（2026-11-25）。

## iOS（Server モード、オフライン）

| id | 操作・状況 | 合格条件 |
|---|---|---|
| E2E-01 | プロジェクト取得だけが 500 を返す | オフライン表示に切り替わらず、無関係な Task を変更でき、サーバーに保存される |
| E2E-02 | サーバー全体が 503、または通信断 | 利用不可を表示し、復旧後に同期を再開する |
| E2E-03 | Blank から通常の Task 作成（通信断中） | 保存でき、再起動後も残り、復旧後にサーバーへ届く |
| E2E-04 | Task 作成時のラベル・プロジェクト（通信断中） | 通信断中も選べて、復旧後に両方がサーバーへ反映される |
| E2E-05 | プロジェクトで絞った Task 一覧 | そのプロジェクトを付けた未同期の Task が、絞り込み結果に出る |
| E2E-06 | Task 作成時の Issue リンク・外部 URL（通信断中） | 保存と再起動を挟んでも詳細画面で見え、同期後も同じリンクが開く |
| E2E-07 | Task のステータス変更（通信断中） | 変更でき、上部に同期待ちが出て、未変更の本文に緑の丸が付かず、復旧後にサーバーへ反映される |
| E2E-08 | ステータス変更後の実績時刻 | `Next`／`Done` にした時刻が、復旧後の画面でも操作した時刻のままになる |
| E2E-09 | ステータス保留中のサーバー側変更 | 他の端末で変えたタイトル・本文や削除が画面に反映され、保留中の操作の内容は保持される |
| E2E-10 | Task の既存コメント編集（入力途中で通信断） | 書き続けて保存でき、復旧後にサーバーの本文と一致する |
| E2E-11 | Article の既存コメント編集（入力途中で通信断） | 書き続けて保存でき、復旧後にサーバーの本文と一致する |
| E2E-12 | Memo の既存コメント編集 | 従来どおり編集でき、通信断中の編集も復旧後に再送される |
| E2E-13 | Task・Article のコメント削除（通信断中） | 編集はできても、削除は引き続き制限される |
| E2E-14 | 同期待ちが 2件 → 1件 → 0件 | 上部の `Waiting to sync` は1つだけ。緑の丸は保留中のコメントだけに付き、同期されたものから消える。0件で上部の表示も消える |
| E2E-15 | 設定の保留・要確認一覧 | 保留中のステータスや、拒否された操作の内容と理由を確認でき、入力した本文を回収できる |
| E2E-16 | Task テンプレートから作成（通信断で再起動後） | テンプレートを選択・保存でき、復旧後に本文・ラベル・プロジェクトがサーバーへ届く |
| E2E-17 | Article テンプレートの選択（通信断中） | 選択でき、本文・ラベル・プロジェクトがフォームに入る |
| E2E-18 | 復旧時のテンプレート更新 | サーバーで変更したテンプレートを復旧時に取り込み、次の通信断でも使える（Task・Article の両方） |
| E2E-19 | 未取得の接続先で Task 作成 | 未取得の案内が出て、Blank で作成フォームに進める |
| E2E-20 | Task 詳細からの関連 Task 作成 | テンプレートを選べて、保存後も元の Task との関連が付く |
| E2E-21 | 子 Task 作成・Memo からの昇格 | 保存でき、親子関係・昇格元との関連が付く |
